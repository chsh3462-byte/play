# 버전별 업데이트

## 2.0 · 2026-11-25 · 황동 살롱

1. **테이블 미술 교체** — 해안 아케이드에서 짙은 펠트, 마호가니, 황동 장식의 살롱으로 옮겼습니다. 로비와 네 게임의 원판, 슬롯 캐비닛, 카드 앞·뒷면과 칩을 다시 그렸습니다.
2. **베팅 조작 변경** — 모노 오빗의 색 버튼·숫자 선택·추가 버튼을 12칸 베팅판으로 통합했습니다. 같은 칸을 여러 번 누르거나 칩 단위를 바꿔 나눠 걸 수 있습니다.
3. **정산 기록 추가** — 각 판의 게임 이름, 결과, 베팅액, 지급액, 순증감을 최근 20판까지 저장합니다. 슬롯 결과에는 멈춘 문양 세 개도 표시합니다.
4. **실행 방식 분리** — 웹 링크, 오프라인 HTML, Python 단일 파일 및 ZIP, Windows EXE를 따로 배포합니다. 1.0 웹 주소도 새 테이블 목록으로 연결됩니다.
5. **지갑 및 설치 수정** — 소리 버튼이 이전 잔액을 저장하던 경로를 제거하고 Python 브라우저 실행에 필요한 외부 패키지를 없앴습니다. [재현 및 수정](FIXES.md)
