# 게임 기능과 규칙

모든 배수는 원금을 포함한 총 지급액입니다. 예를 들어 10칩을 걸어 1.5배를 받으면 15칩이 돌아오고 순이익은 5칩입니다.

| 테이블 | 조작 | 정산 |
| --- | --- | --- |
| 슬롯 | 베팅 단위를 선택하고 릴 돌리기 | 777은 30배, 다른 트리플은 8배, 페어는 1.5배 |
| 룰렛 | 칩 단위를 고른 후 흑·백 1~6의 칸을 눌러 누적. 전체 취소 또는 회전 | 각 베팅별로 색+숫자 2배, 색만 1.5배, 그 밖에는 0. 색이 다르면 숫자가 맞아도 0 |
| 홀덤 | 딜러와 같은 앤티. 프리플롭·플롭·턴·리버에서 체크, 고정 베팅, 콜, 폴드 | 두 장과 공용 다섯 장에서 최고 다섯 장 비교. 승자에게 팟 지급, 동점이면 반씩 분배. 한 거리당 베팅 한 번, 레이즈 없음 |
| 블랙잭 | 히트·스탠드·첫 두 장에서 더블 | 내추럴 2.5배, 일반 승리 2배, 동점 원금 반환. 딜러는 소프트 17에서도 스탠드 |

칩은 1,000개로 시작합니다. 최소 베팅인 10칩 미만이면 연습 칩을 받을 수 있습니다. 진행 중 창을 닫으면 이미 건 칩은 소진되며, 최근 기록에는 정산이 끝난 판만 남습니다. 저장 위치는 해당 브라우저 또는 데스크톱 프로필입니다.

게임 화면에서 카드 패를 글자로도 확인할 수 있습니다. 딜러의 숨긴 패는 공개 시점까지 글자 표시에도 나오지 않습니다.
