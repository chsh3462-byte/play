# 오류와 수정 기록

## NP-01 · 소리를 바꿀 때 잔액을 과거 값으로 덮어씀

- **재현** — 1.0 화면이 잔액 1,000을 읽은 뒤, 같은 저장소 값을 1,250으로 바꾸고 소리 버튼을 눌렀습니다.
- **관찰** — 소리만 바꿨는데 저장된 잔액이 1,000으로 돌아갔습니다. 설정 버튼이 공용 화면 갱신 함수 `sync()`를 호출하고, 이 함수가 실행될 때마다 메모리의 잔액을 다시 저장했습니다.
- **수정** — 잔액 저장을 베팅 차감, 정산, 연습 칩 보충 시점으로 옮겼습니다.
- **검증** — 같은 저장값 변경 후 소리 버튼을 눌러도 1,250이 유지됐습니다. 이 검사는 설정 변경에 따른 덮어쓰기를 다룹니다. 여러 창에서 동시에 진행한 판의 잔액 합산은 지원하지 않습니다.

## NP-02 · 기본 Python 환경에서 실행기 시작 실패

- **재현 조건** — 1.0의 main.py를 pywebview 패키지를 쓸 수 없는 Python으로 실행하면 최상단 `import webview`에서 `ModuleNotFoundError`가 납니다.
- **수정** — 일반 Python 실행 경로는 표준 라이브러리로 오프라인 게임을 기본 브라우저에 엽니다. Windows 번들에서만 pywebview를 불러옵니다.
- **검증** — 단일 .py와 ZIP의 main.py가 동일한 HTML을 생성하고, 이 파일에서 열두 베팅 칸이 모두 렌더링됐습니다. EXE는 별도 게임 창을 띄웠습니다.
