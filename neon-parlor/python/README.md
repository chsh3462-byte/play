# Python으로 실행하기

Python 3.8 이상에서 실행할 수 있습니다. 압축을 모두 풀고 해당 폴더에서 Windows는 `py main.py`, macOS와 Linux는 `python3 main.py`를 실행하세요. 기본 브라우저에 오프라인 게임이 열립니다. pip 설치와 MySQL 접속은 필요 없습니다.

[단일 Python 파일](https://github.com/chsh3462-byte/play/releases/download/neon-parlor-v2.0/NeonParlor.py)은 게임 화면을 내장합니다. 이 파일은 `py NeonParlor.py`로 실행하세요. ZIP판의 main.py는 함께 들어 있는 game.html을 읽습니다. 저장소에서는 ../web의 소스를 읽습니다.

게임 판정과 화면은 JavaScript와 Canvas가 담당합니다. Python은 게임 파일을 준비하고 실행합니다. 공개 웹판, 로컬 파일, EXE의 지갑과 기록은 실행 환경별로 저장됩니다.
